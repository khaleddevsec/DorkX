# Contributing to DorkX

Thank you for your interest in contributing to **DorkX**!

## How Can I Contribute?

### Reporting Bugs
- Check the [Issues](https://github.com/khaleddevsec/DorkX/issues) tab first to see if the issue has already been reported.
- If not, open a new issue with clear steps to reproduce, sample flags, expected behavior, and terminal output.

### Suggesting Enhancements
- Feature requests and ideas for new search engines or filters are welcome!
- Open an issue describing the proposed feature and why it would be beneficial for security workflows.

### Pull Requests
1. Fork the repository.
2. Create your feature branch (`git checkout -b feature/amazing-feature`).
3. Commit your changes (`git commit -m 'Add amazing feature'`).
4. Ensure all tests pass:
   ```bash
   go test -v ./...
   go vet ./...
   ```
5. Push to the branch (`git push origin feature/amazing-feature`).
6. Open a Pull Request.

# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| v3.x    | :white_check_mark: |
| < v3.0  | :x:                |

## Reporting a Vulnerability

Security is a top priority for this project. If you discover a vulnerability or security bug in DorkX, please report it responsibly:

1. **Do not create a public issue.**
2. Send an email to the repository owner or open a [Private Vulnerability Report](https://github.com/khaleddevsec/DorkX/security/advisories/new) on GitHub.
3. Provide detailed steps to reproduce the issue, along with any relevant proof-of-concept information.

You will receive an initial response within 48 hours, and a coordinated fix will be developed and released promptly.
